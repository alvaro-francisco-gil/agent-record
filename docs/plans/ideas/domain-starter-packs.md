# Starter packs per domain

**Priority:** low

## Goal

Offer the bootstrap a starting routing table and directory layout per domain (career,
consultancy, research project, small organisation), so the interview starts from a
sensible shape rather than a blank page.

## Context

Comparable "about me" repos ship templates, and adopters ask what goes where. AGENTS.md
forbids invented example records in this repo, so a pack can only hold **empty
structure**: directory names, routing rows and the questions to ask, never sample facts.

## Design / approach

`skills/bootstrapping-a-system-of-record/assets/packs/<domain>.md`, each a routing table
with placeholder destinations and no content, picked by the bootstrap's first question.

## Open questions

- Do packs narrow the interview too early? The interview should still be able to override
  every row.
